O que é uma regra CSS?

Uma regra CSS é usada para definir o estilo de um elemento HTML. Ela é formada por três partes principais:

  • Seletor: indica qual elemento será estilizado (ex: button).
  • Propriedade: define o que será alterado (ex: background-color).
  • Valor: indica como será a alteração (ex: yellow).

Exemplo: no código "button:hover { background-color: yellow; }", o seletor é button:hover, a propriedade é background-color e o valor é yellow.
